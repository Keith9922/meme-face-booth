# 表情复刻机 · Mimic Photo Booth

线下活动签到用的互动拍照装置。**走到镜头前做个表情或摆个动作，它实时告诉你最像哪张表情包；够像了 3-2-1 自动拍照，展示结果。**

插电即用，无需设置和调参。纯前端，无后端，无数据库，模型全本地，断网可用，不上传任何数据。

---

## 快速开始

```bash
./setup.sh          # 拉模型和 wasm（约 51MB，只需一次）
node serve.mjs      # 起本地服务
```

打开 <http://localhost:5173>，点「开始」。

> `getUserMedia` 只在 **https 或 localhost** 下可用，直接双击 `index.html` 打不开摄像头。

**表情包素材需要自备**（见「素材」一节），仓库里 `memes/` 是空的。

## 流程

```
待机 ──► 看到人，实时匹配 ──► 任一通道 ≥70% 且稳住 ──► 3-2-1 ──► 拍 ──► 展示结果
                  ▲                                    │              │
                  └──────────── 掉太多则中断 ◄─────────┘   14 秒后自动回待机
```

现场无需操作。兜底手段：**点画面**或**按空格**可手动触发倒计时，`Esc` 回待机。

## 双通道匹配

两条通道各自独立打分，**任意一条达标就拍** —— 脸做到位，或者姿势摆到位，都算你赢。

| 通道 | 维度 | 看什么 |
|---|---|---|
| **表情** | 41 维 blendshapes | 脸做得像不像 |
| **动作** | 14 维肩宽归一化上半身关键点 | 姿势摆得像不像（抱头 / 托腮 / T字手…） |

两条通道的目标**都从表情包图片自动提取**，不用录制、不用标注。丢一张新图进来立刻可用。

```
表情包图片 ──► FaceLandmarker(IMAGE) ──► 41 维 ─┐         ┌─► 表情分 ─┐
           └─► PoseLandmarker(IMAGE) ──► 14 维 ─┼─ 距离 ──┤          ├─► 取高者
你 ────────► FaceLandmarker(VIDEO) ──► 41 维 ───┤         └─► 动作分 ─┘
           └─► PoseLandmarker(VIDEO) ──► 14 维 ─┘
```

### 表情通道的 41 维

MediaPipe 输出 52 个 blendshape 系数，剔掉三类：

| 剔除 | 原因 |
|---|---|
| `_neutral` | 不是表情 |
| `eyeLook*`（8 个） | 是「眼球往哪看」不是表情。实测有的表情包 top-2 就是它，用户没法也不该复刻 |
| `eyeBlink*`（2 个） | 瞬时动作，要求用户「保持眨眼」很怪。眯眼 `eyeSquint*` 保留 |

距离用加权 RMS，`wᵢ = 0.3 + max(tᵢ, uᵢ)` —— 权重跟着「目标在意的维度」走，同时你多做出来的动作也一样被罚。

### 动作通道的 14 维

以两肩中点为原点、**肩宽为单位**归一化，取鼻 / 双肩 / 双肘 / 双腕。远近和身高自动无关，正好覆盖「手在身体的哪个位置」。

**左右镜像容忍**：你抬右手、图里抬左手，照样算像（正反两个朝向取更近的）。

肩膀或双腕都看不见时该通道自动停用（脸部特写类表情包就只走表情通道）。

### 四道防抖（缺一个现场就会抽风）

| 机制 | 治什么 |
|---|---|
| **摆烂闸门** | 脸越接近「面无表情」，表情分打折越狠 |
| **躺平闸门** | 身体越接近「自然站姿」，动作分打折越狠 —— 没它的话，一个手臂放下的表情包会让站着不动直接拿高分 |
| **换图迟滞** | 新候选要比当前那张明显更好才准换，否则相近的两张会疯狂跳 |
| **去抖帧数** | 必须**同一张**连续命中 7 帧才开始倒计时，中途换图重新数 |

## 实测数据

12 张真人表情包上测得（`__mimic.audit()` 可复现）：

| 项 | 结果 |
|---|---|
| 表情向量提取成功率 | 12/12（卡通、动物、侧脸提取不到，会被跳过） |
| 动作向量提取成功率 | 8/12（另外 4 张是脸部特写，看不到手臂） |
| 表情两两距离 | 最小 0.102 · 中位 0.367 · 最大 0.516 |
| 动作两两距离 | 最小 0.130 · 中位 0.399 · 最大 0.837 |
| 认真做 → 匹配正确率 | **12/12**，平均 96.8 分，全部达标 |
| 面瘫站着不动 | **判为「没做」，不触发** |
| 只有脸看不到身体 + 面无表情 | **判为「没做」，不触发** |
| 做表情但身体不动 | 86 分（走表情通道）→ 触发 |
| 摆动作但面无表情 | 100 分（走动作通道）→ 触发 |
| 推理耗时（GPU） | 人脸 7.8 ms/帧；姿势隔帧跑 |
| 首帧 | ~5 s（GPU shader 编译），已在加载页预热掉 |

> 动作通道的 `pD1=0.60` 就是照着上面那行「动作两两距离中位 0.399」定的。放到默认的 0.95 时，两个**完全不同**的姿势也能拿 65 分，站着不动就会误触发。

## 素材

`memes/` 放图，`memes/manifest.json` 登记：

```json
{ "memes": [ { "file": "shock.jpg", "name": "震惊", "code": "M-01" } ] }
```

首次加载会自动提取两路向量并缓存进 localStorage。换了图记得 `__mimic.clearCache()`。

### 选图建议

- **优先选能看到上半身的**，这样动作通道才有得比，也更好玩
- 卡通、动物、侧脸提取不到人脸，会被自动跳过
- 表情/动作幅度要大，太淡的会被「摆烂闸门」和「躺平闸门」压住

### 张数：25–30 张是上限，不是越多越好

人脸表情空间就那么大。实测 12 张里最近的一对距离只有 0.102；硬塞 50–60 张必然出现大量近邻，**匹配会在几张之间反复横跳**。动作通道稍宽松些，但同理。

### 版权

**不要用网络流行表情包。** 经典 meme 几乎都是有主的（原摄影师、被拍的真人），活动现场使用并打印实物属于商用。请用：

- 自己拍的（**推荐，而且匹配更准** —— 与现场同一摄像头、同样光照和角度，条件对齐）
- Pexels / Unsplash / Pixabay 等允许商用的图库
- AI 生成的人脸

## 调试

现场界面**没有任何旋钮**。需要二次标定时加 `?dev=1` 打开侧栏（实时排行 + 参数滑杆，改动存 localStorage，不影响正常访问）：

```
http://localhost:5173/?dev=1
```

控制台：

```js
__mimic.audit()        // 库体检：哪些图没动作向量、哪几对挨太近
__mimic.clearCache()   // 换图后清缓存重新提取
__mimic.P              // 当前参数
```
