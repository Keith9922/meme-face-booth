# 表情复刻机 · Mimic Photo Booth

线下活动签到用的互动拍照装置。**走到镜头前随便做个表情，它实时告诉你最像哪张表情包；够像了保持住，倒数三秒自动拍，出一张竖版小票直接打印。**

纯前端，无后端，无数据库，模型全本地，断网可用，不上传任何数据。

---

## 快速开始

```bash
./setup.sh          # 拉模型和 wasm（约 51MB，只需一次）
node serve.mjs      # 起本地服务
```

打开 <http://localhost:5173>。

> `getUserMedia` 只在 **https 或 localhost** 下可用，直接双击 `index.html` 是打不开摄像头的。

**表情包素材需要你自己准备**（见下方「素材」一节），`memes/` 在仓库里是空的。

## 它是怎么工作的

```
表情包图片 ──► FaceLandmarker(IMAGE) ──► 41 维 blendshapes ──┐
                                                            ├─► 加权距离 ─► 取最近的一张 ─► 相似度%
你的脸 ─────► FaceLandmarker(VIDEO) ──► 41 维 blendshapes ──┘
```

没有训练，没有标注。**表情包图片本身就是目标向量** —— 丢一张新图进来立刻可用。

### 41 维怎么来的

MediaPipe 输出 52 个 blendshape 系数，剔掉三类：

| 剔除 | 原因 |
|---|---|
| `_neutral` | 不是表情 |
| `eyeLook*`（8 个） | 是「眼球往哪看」不是表情。实测有的表情包 top-2 就是它，用户没法也不该复刻 |
| `eyeBlink*`（2 个） | 瞬时动作，要求用户「保持眨眼」很怪。眯眼 `eyeSquint*` 保留 |

### 距离

```
d = sqrt( Σ wᵢ(uᵢ−tᵢ)² / Σ wᵢ )      wᵢ = 0.3 + max(tᵢ, uᵢ)
```

权重跟着「目标在意的维度」走，同时你多做出来的动作也一样被罚。归一化后 `d ∈ [0,1]`。

### 相似度

```
相似度 = 100 · clamp((d1 − d) / (d1 − d0))^γ · 摆烂打折
```

`d0=0.005 / d1=0.44 / γ=1` 不是拍脑袋定的，是扫参扫出来的：先量出「按目标做到 N 成」对应的实际距离，再搜使分数落在预期档位的组合。

### 三道防抖（缺一个现场就会抽风）

| 机制 | 治什么 |
|---|---|
| **摆烂闸门** | 「面无表情」也在候选池里。你不做表情时它赢 → 不出图、不计分、不触发 |
| **换图迟滞** | 新候选要比当前那张近一截才准换。否则相近的两张会疯狂跳 |
| **去抖帧数** | 必须**同一张**连续命中 N 帧才开始倒计时，中途换图重新数 |

## 实测数据

在 12 张真人表情包上测得（`__mimic.auditLib()` 可复现）：

| 项 | 结果 |
|---|---|
| 真人表情包自动提取成功率 | 12/12（卡通、动物、侧脸提取不到，会被标记不可用） |
| 表情包两两距离 | 最小 0.102 · 中位 0.367 · 最大 0.516 |
| 认真做 → 匹配正确率 | **12/12**，平均 91 分 |
| 随便糊弄 → 匹配正确率 | 7/12，平均 **73 分**（不触发，符合预期） |
| 面瘫站着不动 | 判为「没做表情」，不触发 |
| 推理耗时（双模型，GPU） | **7.8 ms/帧**；CPU 兜底 56 ms/帧 |
| 首帧 | ~5 s（GPU shader 编译），已在加载页预热掉 |

## 素材

`memes/` 需要你自己放图，并在 `memes/manifest.json` 登记：

```json
{ "memes": [ { "file": "shock.jpg", "name": "震惊", "code": "M-01" } ] }
```

也可以直接把图片**拖进页面**，会自动提取、查重、入库（存 localStorage）。超过 30 张建议改放 `memes/` 文件夹，浏览器存不下。

### 版权

**不要用网络流行表情包。** 经典 meme 几乎都是有主的（原摄影师、被拍的真人），活动现场使用并打印实物属于商用。请用：

- 自己拍的（**推荐，而且匹配更准** —— 与现场同一摄像头、同样光照和角度，条件对齐）
- Pexels / Unsplash / Pixabay 等允许商用的图库
- AI 生成的人脸

### 张数：25–30 张是上限，不是越多越好

人脸表情空间就那么大。实测 12 张里最近的一对距离只有 0.102；硬塞 50–60 张必然出现大量近邻，**匹配会在几张之间反复横跳**。

配套工具：

- **入库自动查重** —— 距离 < 0.07 直接挡下，并告诉你跟哪张撞了
- **库体检**按钮 —— 列出「挨太近」的配对和「表情太淡」的图
- **导出清单** —— 导出 `manifest.json`

## 打印

竖版小票，80mm 热敏纸（`@page size: 80mm auto`），版式：

```
表情复刻机 / MIMIC PHOTO BOOTH
────────────────────────────
01  YOU        [摄像头照片]
02  MATCH      [表情包]
        你是「震惊」
           91.4%
────────────────────────────
NO.0001              AUTO
     2026-07-31 14:39:16
```

走 `window.print()` + 一个纯图打印容器，**不挑打印机型号**，能装成系统打印机即可。输出灰度，点阵抖动交给打印机。

> **无人值守必须加启动参数**，否则每张都会弹系统打印对话框：
> ```
> open -a "Google Chrome" --args --kiosk-printing
> ```

## 调参

右下角滑杆，改完实时生效，存在 localStorage。

| 旋钮 | 作用 |
|---|---|
| `d1` 零分距离 | **主旋钮**：调小变难，调大变松 |
| `d0` 满分距离 | 距离 ≤ d0 即 100% |
| `γ` 曲线 | >1 让高分区更难拿 |
| 摆烂闸门 | 要求你做得多夸张才开始计分 |
| 换图迟滞 | 越小越黏，越不容易乱跳 |
| 触发阈值 / 去抖帧数 / 平滑 α / 倒计时 / 中断余量 | 见界面提示 |

控制台调试：

```js
__mimic.auditLib()      // 库体检
__mimic.demoShot()      // 没摄像头也能预览小票版式
__mimic.T               // 当前参数
```
